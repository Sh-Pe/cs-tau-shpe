	\subsection*{Why C?}
	\begin{itemize}
		\item C is \textit{compact}: there are few reserved keyword, and powerful set of operators
		\item C is \textit{efficient}: no interpretation layer 
		\item C is \textit{Modular} and \textit{Typed}
		\item C is the native language of UNIX
		\item C is the basis of C++
	\end{itemize}
	
	\subsection*{C vs. Java}
	\begin{itemize}
		\item Java is somewhat based on C
		\item C is procedural and not object-oriented
		\item There's no GC in C
	\end{itemize}
